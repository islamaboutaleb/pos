# نظام الصيانة الوقائية للكاميرات

نظام كامل (Flask + SQLite) لإدارة المهام التشغيلية ومهام الصيانة الوقائية لكاميرات المراقبة، مع واجهة عربية عصرية ومتجاوبة بالكامل (RTL).

## المميزات

- تسجيل دخول بصلاحيتين: **مدير** (إنشاء/تعديل/حذف المهام، إدارة الفنيين) و **فني** (عرض وتحديث حالة مهامه فقط).
- **لوحة إدارة كاملة للمدير** (قسم "الإدارة" في الشريط الجانبي) تشمل:
  - **المناطق والفروع**: إضافة/تعديل/حذف المناطق، وإضافة/تعديل/حذف الفروع داخل كل منطقة، مباشرة من الواجهة دون الحاجة لتعديل قاعدة البيانات يدوياً.
  - **الفنيون**: إضافة/تعديل/حذف الفنيين، مع عرض حالة كل فني (مفعّل/غير مفعّل) وما إذا كان مرتبطاً بحساب دخول.
  - **المستخدمون**: إضافة/تعديل/حذف حسابات تسجيل الدخول (مدير أو فني)، ربط حساب الفني بسجل الفني المناسب، تفعيل/تعطيل الحسابات، وإعادة تعيين كلمات المرور.
  - حماية تلقائية تمنع حذف أو تعطيل آخر حساب مدير نشط في النظام، ومنع حذف منطقة أو فني مرتبط بمهام/حسابات قائمة دون تنبيه واضح بالسبب.
- تحديد **المنطقة المستهدفة** (الصالات، المخازن، المختبرات، الأقسام، الفروع الخارجية) مع فروعها التفصيلية.
- اختيار فروع محددة أو **"تحديد كل الفروع"** للمنطقة دفعة واحدة.
- تمييز واضح بين **المهام العادية** و **مهام الصيانة الوقائية للكاميرات** (أيقونة وألوان مختلفة لكل نوع).
- نوع الصيانة: **وقائية / تنظيف / طارئة** (قائمة منسدلة).
- حالات المهمة: **قيد الانتظار / قيد التنفيذ / مكتمل**.
- عند التحويل إلى "مكتمل" تظهر نافذة لتحديد **الفروع التي تم إنجازها فعلياً** (مع خيار "كل الفروع").
- لوحة إحصائيات سريعة (إجمالي، قيد الانتظار، قيد التنفيذ، مكتمل، صيانة كاميرات).
- فلاتر: الحالة، المنطقة، الفني، البحث بالكود/العنوان.
- **تصدير Excel و PDF** (تقرير صيانة الكاميرات فقط، أو تقرير شامل لكل المهام) بدعم كامل للغة العربية واتجاه RTL.
- تصميم عصري متجاوب على كل أحجام الشاشات (موبايل / تابلت / شاشات كبيرة).

## التشغيل

```bash
# 1. تثبيت المتطلبات
pip install -r requirements.txt

# 2. إنشاء قاعدة البيانات وتعبئتها بالبيانات الأساسية (مرة واحدة فقط)
python seed_data.py

# 3. تشغيل النظام
python app.py
```

ثم افتح المتصفح على: `http://127.0.0.1:5000`

### بيانات الدخول الافتراضية

| الدور  | اسم المستخدم | كلمة المرور |
|--------|--------------|--------------|
| مدير   | admin        | admin123     |
| فني    | tech1        | tech123      |

> يفضّل تغيير كلمات المرور هذه مباشرة بعد أول استخدام (عبر تعديل قاعدة البيانات أو إضافة شاشة لتغيير كلمة المرور).

## هيكل المشروع

```
camera_maintenance/
├── app.py                  # تطبيق Flask الرئيسي (كل الـ API)

├── schema.sql                # هيكل قاعدة البيانات (SQLite)
├── requirements.txt
├── maintenance.db             # تُنشأ تلقائياً بعد تشغيل seed_data.py
├── templates/
│   └── index.html            # الواجهة (صفحة واحدة SPA)
└── static/
    ├── css/style.css         # التصميم
    ├── js/app.js              # منطق الواجهة (Vanilla JS)
    └── fonts/                  # خط عربي مستخدم في تصدير PDF
```

## المناطق والفروع المُدرجة مسبقاً

- **الصالات**: الإنتاج التام، المعجون، الزيت، السيليكون، الاسمنتيات القديم، التنر، المدينة باك، الوافي
- **المخازن**: الصرف، المنظومة1، المنظومة2، الكربونات، العبوات، التالف
- **المختبرات**: الدور الأرضي، الأول، الثاني، الثالث
- **الأقسام**: 16 فرعاً (الموارد البشرية، شئون قانونية، أرشيف، مراجعة، حسابات، ماركتنج... إلخ)
- **الفروع الخارجية**: معارض، ياقوت، أصول

يمكن الآن إضافة أو تعديل أو حذف المناطق والفروع **مباشرة من واجهة النظام** (قسم "الإدارة" → "المناطق والفروع") دون الحاجة لتعديل قاعدة البيانات يدوياً.

## ملاحظات تقنية

- قاعدة البيانات تعمل بنظام **WAL** لتحسين الأداء مع تعدد الاتصالات.
- تم تفعيل **Foreign Keys** والحذف المتسلسل (Cascade) لجدول `task_branches` المرتبط بكل مهمة.
- التصدير لملف PDF يستخدم خط `Noto Naskh Arabic` مع `arabic_reshaper` و `python-bidi` لضمان عرض صحيح للنص العربي.
- لإضافة/تعديل/حذف الفنيين أو حسابات تسجيل الدخول: من الواجهة (قسم "الإدارة") إذا كنت مديراً.

## نشر النظام (Production)

للاستخدام الفعلي على خادم داخلي، يُفضّل تشغيله عبر `gunicorn` بدلاً من خادم التطوير المدمج:

```bash
pip install gunicorn
gunicorn -w 4 -b 0.0.0.0:8000 app:app
```

ولا تنسَ تغيير `app.secret_key` في `app.py` إلى مفتاح سري عشوائي وقوي قبل النشر.
